# Food Delivery System (Java Project)

Hey,

Welcome to my **Food Delivery System** — a Java-based desktop application that lets users browse food items, place orders, and manage deliveries, just like a mini Uber Eats or Mr D, but simpler.

It’s built using **Object-Oriented Programming (OOP)** concepts with a GUI interface, so everything runs from a clean, user-friendly app window.

---

# What This Project Does

With this system, you can:

- View a list of available food items
- Add food items to your order
- Remove items from your order if you change your mind
- Select quantities
- See your total price update
- Calculate delivery and tax charges
- Place your order and view your order summary
- Track active orders
- Automatically update order statuses
- Save and load application data

---

# Features

The Food Delivery System includes:

- Java Swing graphical user interface
- Food menu management
- Order creation
- Quantity selection
- Order item removal
- Automatic total calculations
- Delivery charge calculation
- Tax calculation
- Order summaries
- Active order tracking
- Automatic order status updates
- File handling for saving and loading data
- Object-Oriented Programming structure

# How to Run the Project

The application is available as a **Windows version**.

The Windows package includes a **bundled Java runtime**, so Java does not need to be installed separately.

---

# Windows Version

## Download the Windows Version

Go to the latest GitHub release:

[Download Food Delivery System for Windows](https://github.com/calebnayager/FoodDeliverySystemv/releases/latest)

On the release page:

1. Scroll down to the **Assets** section.
2. Download:

`Food-Delivery-System-Windows.zip`

---

## How to Run the GUI

After downloading the ZIP file:

1. Open your **Downloads** folder.
2. Right-click `Food-Delivery-System-Windows.zip`.
3. Select **Extract All**.
4. Open the extracted **Food Delivery System** folder.
5. Double-click:

`Food Delivery System.exe`

6. The Food Delivery System GUI will launch.

You do **not** need to install Java separately.

---

# How to Operate the System

Once the GUI opens, you can use the application to manage food orders.

## 1. View the Menu

The application displays the available food items.

Each food item includes information such as:

- Food name
- Price

---

## 2. Add Food to Your Order

- Select the food item you want.
- Choose the quantity.
- Add the item to your order.
- The item will appear in your order.
- The total price will update.

You can add multiple items to your order.

---

## 3. Remove Items

If you change your mind about an item, you can remove it from your order.

The total price will update automatically.

---

## 4. Place an Order

Once you are happy with your selection:

- Place your order.
- The system will display your order summary.
- The total cost will be calculated.
- Delivery and tax charges will be included.

---

## 5. Track Your Order

After placing an order, you can view your active orders.

The order status automatically updates over time to simulate the progression of a food delivery.
