Food Delivery System (Java Project)

Hey,

Welcome to my Food Delivery System — a Java-based desktop application that lets users browse food items, place orders, and manage deliveries, just like a mini Uber Eats or Mr D, but simpler.
It’s built using Object-Oriented Programming (OOP) concepts with a GUI interface, so everything runs from a clean, user-friendly app window.

 What This Project Does

With this system, you can:

- View a list of available food items 🍕

- Add food items to your order 🛒

- Remove items from your cart if you change your mind

- See your total price update live

- Place your order and view your order summary

- Save and load your data automatically when reopening

 How to Run the Project?
 
1.Make sure you have Java 8 or higher installed and an IDE such as Jgrasp.

2.Download the file "FoodDeliverySystem.jar." from Github.

3.Just double-click it to run — the GUI will pop up instantly.


How to Operate the System?

Here’s how to get started once the program opens:

1. Viewing the Menu

- When the app starts, you’ll see a menu of food items (e.g., burgers, pizzas, drinks).

- Each item shows:

- Food name

- Price


2. Adding Food to Your Order

- Click on a food item you want.

- Choose your quantity.

- Click Add Item
  
- The item will appear in your cart and the total cost will update. You can add multiple items if you like.


3. Placing an Order

- Once you’re happy with your selection, click Place Order.

- The system will show a summary:

- All items ordered

- Total cost

- Delivery confirmation message


4. Tracking order

- The order status will update automatically every one minute.

- Once order is placed click the option "track order" to view all orders.

*Notes*

1. Object-Oriented and GUI based.

2. You can easily add new food items in the code.

3. If you wish to view the code click the project folder on Github "src/com/fooddelivery" and SELECT ONLY THE ".JAVA" FILES TO VIEW CODE NOT THE ".CLASS" AS THOSE ARE THE COMPILED FILES.
